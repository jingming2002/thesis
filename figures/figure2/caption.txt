Figure X. Functional composition and lifestyle associations of pig gut auxiliary viral genes. (A) All 32 mapped functional modules, ordered by protein count within each AVG class. Numbers indicate exact counts; horizontal axis ranges differ among classes. Complete module-level data and protein annotations are provided in Supplementary Table S2. (B) Functional carriage frequencies in predicted virulent (orange; n = 6,061) and temperate (teal; n = 3,076) vOTUs, with odds ratios (virulent relative to temperate) and 95% confidence intervals. All 32 modules are shown, ordered by pooled carrier count within each class. Arrows indicate confidence intervals extending beyond the plotted range; Inf denotes an infinite odds-ratio estimate. Filled markers indicate BH-adjusted q < 0.05; open markers indicate q >= 0.05. P values were obtained using two-sided Fisher's exact tests and adjusted across all 32 modules.
