Figure X. Functional repertoires of auxiliary viral genes across predicted viral lifestyles. All 32 mapped functional modules are shown. Left, percentages of virulent (orange; n = 6,061) and temperate (teal; n = 3,076) vOTUs carrying each module. Right, odds ratios (virulent relative to temperate) and 95% confidence intervals. Filled markers indicate BH-adjusted q < 0.05; open markers indicate q >= 0.05. Modules were ranked by pooled carrier counts. TA-associated candidates use the revised annotation subset documented in the accompanying audit.

Methods. Analyses and plotting were performed in R v4.3.3 using stats and grid. For each functional module, carriage was defined as the presence of at least one mapped gene per eligible vOTU. Lifestyle associations were assessed using two-sided Fisher's exact tests, with conditional odds ratios and exact 95% confidence intervals. P values were adjusted across all 32 modules using the Benjamini-Hochberg method. All 32 modules were displayed, ordered by pooled carrier count within each AVG class. Arrows denote confidence intervals extending beyond the plotted range; Inf denotes an infinite odds-ratio estimate.
